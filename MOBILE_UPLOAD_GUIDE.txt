동국대학교 3D 캠퍼스 최종 업로드 패키지

폴더 구조:
.github/workflows/deploy.yml  (숨김 폴더, GitHub Actions 자동 배포 설정)
public/index.html            (최신 게임 HTML)
src/index.js                (Cloudflare Worker + 멀티플레이 서버)
wrangler.toml               (Cloudflare 설정)
package.json                (의존성)
README.md                   (기존 안내)

중요: ZIP을 GitHub에 파일 하나로 올리는 것만으로는 작동하지 않습니다.
ZIP을 휴대폰에서 압축 해제한 뒤 폴더 구조를 유지해 각 파일을 저장소에 올려야 합니다.
.github 폴더는 숨김 폴더이므로 갤럭시 내 파일에서 숨김 파일 표시를 켜야 보일 수 있습니다.

GitHub 저장소의 기존 public/index.html, src/index.js, wrangler.toml, package.json은 교체하고,
.github/workflows/deploy.yml을 새로 추가하세요.

GitHub 저장소 Settings > Secrets and variables > Actions에서
CLOUDFLARE_API_TOKEN, CLOUDFLARE_ACCOUNT_ID가 설정되어 있어야 자동 배포가 됩니다.

주의: wrangler.toml의 Worker 이름이 기존 배포한 이름과 다르면 새 주소로 배포될 수 있습니다.
기존 Worker 이름을 확인하고 name 항목을 일치시켜야 합니다.

이 패키지는 소스 코드/구문 검증용입니다. 실제 휴대폰 WebGL 실행, 서버 배포 및 천수경 재생의
완전한 동작은 실기기에서 검증하지 못했습니다.
